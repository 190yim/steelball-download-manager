# Contributing

Thanks for helping make SteelBall better.

## Before opening an issue

- Check for an existing issue describing the same problem.
- Include the Chrome version, operating system, and the steps needed to reproduce it.
- Remove private URLs, filenames, and personal information from screenshots or logs.

## Pull requests

- Keep changes focused and explain the user-facing effect.
- Avoid adding third-party tracking, analytics, or remote assets.
- Do not commit generated build artifacts or private download data.
- Update the README when behavior or permissions change.

By submitting a contribution, you agree that it may be distributed under the project's MIT License.
